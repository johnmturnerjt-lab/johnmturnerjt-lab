### 🛠️ Featured Project: SignalExplorer Showcase
👉 **[Explore the Repository](https://github.com/johnmturnerjt-lab/SignalExplorer-Showcase)**

A commercial-grade, cross-platform **4-channel Signal Generator and Oscilloscope suite** built from the ground up to demonstrate modern .NET and Avalonia UI performance engineering:

* **Zero-Allocation Streaming:** High-frequency real-time data pipelines between the core generator engine and UI layer using `System.Threading.Channels` and `Span<T>`.
* **Bespoke Rendering & UI:** Custom-rendered **SkiaSharp** waveform controls, dynamic theme variants, and compiled bindings (`x:DataType`) for maximum execution speed.
* **Clean Architecture:** Modular MVVM design built on `CommunityToolkit.Mvvm`, SOLID principles, and Dependency Injection.
* **AI-First Engineering:** Architected, iterated, and hardened using an AI-first workflow with Google Gemini, progressing from initial prototype to commercial productisation.
